## ⚙️ الإعداد السريع

### 1️⃣ Firebase

**أ) أنشئ مشروع**
اذهب إلى [Firebase Console](https://console.firebase.google.com) → Add project

**ب) فعّل Firestore**
Build → Firestore Database → Create database

**ج) فعّل Authentication**
Build → Authentication → Email/Password

**د) أضف النطاق ⚠️ مهم**
```
Authentication → Settings → Authorized domains
أضف: alimamdouhh.github.io
```

**هـ) Rules**
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{docId} {
      allow read: if true;
      allow write: if request.auth != null
        && request.auth.token.email in [
          'alimamdouhh369@gmail.com',
          'elloul369@gmail.com'
        ];
    }
  }
}
```

### 2️⃣ تشغيل محلي

```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

> ⚠️ لا تفتح index.html مباشرة من file://
